# Images in history lessons and tests (BDFN, 2026-09-28)

- Every image carries a visible provenance label by type: photograph, period artwork, later artwork, AI reconstruction. Stored metadata: source URL, license, attribution, retrieval date, content hash, and for AI images the generator, model, prompt and seed.
- Real images come from open-license archives (for example Wikimedia Commons, Library of Congress, Smithsonian Open Access), with the license recorded.
- Later artwork is itself interpretation and can be wrong. Example: Leutze's "Washington Crossing the Delaware" (1851) shows the Stars and Stripes, which was adopted in June 1777, after the December 1776 crossing.
- AI images are always labeled as AI in an age-appropriate way, and they pass a sourced accuracy checklist (clothing, technology, architecture, people, setting) by the verifier role, then BDFN's approval before any learner sees them. Content Credentials (C2PA) metadata is kept when present.
- An AI image is never evidence and never a grading key for a factual question. It can illustrate, or be the object of a deliberate exercise ("what here is wrong for 1776?").
